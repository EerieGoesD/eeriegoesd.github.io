Bear in Mind

A list for the things you are afraid of forgetting.

Type it into the box at the top, press Enter, and it is on the list. Add a description if it needs one. Tick it off when it is done. Nothing to set up, no account, and it works with no internet.

Windows Microsoft Store
Chrome In review

What it does

One box, one keystroke

The box sits at the top of the window and is ready the moment it opens. Type and press Enter.

Descriptions when you need them

Any entry can carry a longer note. It stays hidden behind an arrow, so a list of short entries stays a list.

Change anything later

Edit the text of an entry, or add a description to one that never had one.

Tick it off

Ticking an entry drops it into a Done section, struck through. Untick it to put it back.

See how far you are

A bar under the name shows how much of the list is done, red through amber to green. It can be switched off.

Take it with you

Export writes the list to a file and Import reads one back, adding to what is already there.

Where your list lives

On your own computer, and nowhere else. There is no account, no sign-in and no sync. The desktop app keeps two plain files in its own folder; the browser extension keeps its list in the browser's own storage. Neither one contacts anything on its own, so both work with the network unplugged.

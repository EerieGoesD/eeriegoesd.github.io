Privacy Policy

Last updated: June 14, 2026

SideWire is a local-first file transfer tool. This policy explains what data is collected when you use the app, particularly when using Remote mode via the SideWire relay server.

Local Mode (Same Wi-Fi)

When using Local mode, no data leaves your local network. All communication happens directly between your devices via your router. No data is sent to any external server. SideWire does not collect, store, or transmit any information when used in local mode.

Remote Mode (Relay Server)

When using Remote mode, your device connects to the SideWire relay server at sidewire-relay.fly.dev to facilitate connections between devices that are not on the same network. The following data is temporarily processed:

  • IP address — Your public IP address is logged for abuse prevention and rate limiting purposes only.
  • Device name — The name you provide (e.g. "John's Phone") is shared with other devices in the same room.
  • Room code — The room identifier is stored while the room is active.
  • Message history — Text messages sent in a room are stored in memory while the room exists. History is deleted when the host leaves or the room expires.
  • Files — Files sent through the relay are not stored on the server. They are relayed in real-time and discarded immediately after delivery. The file name and size are logged temporarily.

Data Retention

  • IP addresses and activity logs are kept in memory (up to 10,000 entries) and are lost on server restart.
  • Fly.io retains server logs for up to 7 days for operational purposes.
  • Room data is deleted immediately when the host disconnects or the room is closed.
  • No data is written to permanent storage or databases.

Why We Log IP Addresses

IP logging is used solely for abuse prevention — detecting and rate-limiting users who send excessive files or try to disrupt the service. We do not sell, share, or use IP data for any other purpose.

Third-Party Services

The relay server is hosted on Fly.io. Fly.io's privacy policy applies to their infrastructure. See Fly.io Privacy Policy.

Your Rights (GDPR / CCPA)

Depending on your jurisdiction, you may have the right to:

  • Request access to data we hold about you
  • Request deletion of your data
  • Object to processing

Since SideWire does not use accounts and does not persistently store personal data, these requests are inherently fulfilled — we have no permanent records to delete. If you have concerns, contact us at the address below.
